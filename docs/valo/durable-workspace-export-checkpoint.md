# Durable workspace-data export implementation checkpoint

This private development change replaces the account page's primary synchronous export action with a persisted preparation journey. The synchronous attachment remains an explicit fallback. Neither path represents complete fulfilment across identity, staff-audit, payment-provider or other external systems.

Requests have an idempotency key, saved status and bounded progress, optimistic action version, cancellation, two manual retry cycles and three attempts per cycle. The worker uses a persisted generation and lease, bounded pages and a 128 MiB file cap. A stopped worker can be recovered independently of transport retention. Ready files are available for 24 hours as a product policy, then withdrawn and scheduled for cleanup. Cancellation removes availability; it cannot recall a browser-owned or previously downloaded copy.

JSON generations reserve an exact workspace/object key before collection or external I/O. Document and workspace jobs share the existing private asset and pending-object registries with an exactly-one-job binding. Both pending and completed keys enter the existing signed erasure inventory. Historical erasure phase indices are unchanged. Ordinary cleanup respects recorded deletion holds and delegates all quarantined keys to authenticated erasure replay. Repeated cleanup records cover late accepted writes.

Download fetches and verifies a private bounded scratch file before the final live session check. Current membership, privacy, job version, cancellation and expiry are checked again after storage waits. Job and membership locks cover release; earlier committed cancellation/revocation wins. Commands arriving after release cannot revoke already delivered bytes. No object key is returned to the client.

The account UI supports reloadable history, progress, retry, cancellation, ready-file withdrawal and native attachment download without collecting the full file in browser JavaScript. Account changes unmount and abort the previous account's controls.
